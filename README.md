Requirements:
- Jenkins Maven tool
- A container runtime (podman or docker)
- Git PAT
- OCI credentials: A separated Jenkins Username/Password Kind of credentials with Docker username and RW mode PAT
- AWS_CRED_ID 
  A separated Jenkins Username/Password Kind of credentials of IAM user's credentials, 
  aws_access_key_id (as Username) amd aws_secret_access_key (as Password)
- Terraform binary should be exist in agent to deploy infrastructure
